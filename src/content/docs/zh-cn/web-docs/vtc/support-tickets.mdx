VTC 支持功能为成员提供了直接联系工作人员的渠道——该渠道独立于 [TrucklineMP 自身的支持系统](/zh-cn/web-docs/account/support-tickets/)（后者用于处理平台级问题）。

## 成员如何提交工单

1. 前往您的 VTC 或 VBC 的个人资料页面
2. 打开 `/vtc/@handle/support`（或 `/vbc/@handle/support`）
3. 选择分类，填写主题和消息，然后提交

工作人员会收到通知，并可以直接在工单对话中回复。

---

## 工作人员如何管理工单

1. 打开您的 **管理** 面板
2. 选择 **支持**

### 工单标签页

- 按状态（**开放**、**处理中**、**等待用户回复**、**已解决**、**已关闭**）、分类、优先级、负责人或搜索内容筛选
- 认领无人负责的工单，或筛选为 **分配给我** 的工单
- 在工单对话中回复、更改状态和设置优先级

概览指标会显示开放工单数、等待用户回复的工单数、分配给您的工单数、无人负责的工单数以及平均满意度评分。

### 设置标签页

拥有 **支持设置** 权限的工作人员可以配置：

- **分类** - 带颜色的自定义工单分类
- **预设回复模板** - 用于常见问题的一键式回复

## 权限

| 权限 | 授权内容 |
|------------|-----------------|
| `support.view` | 查看工单 |
| `support.reply` | 回复工单 |
| `support.assign` | 将工单分配给工作人员 |
| `support.close` | 解决并关闭工单 |
| `support.manage` | 完整控制工单流程 |
| `support.settings` | 配置分类和模板 |

请通过 [角色与权限](/zh-cn/web-docs/vtc/roles-permissions/) 中的 **权限** 标签页分配这些权限。此外，在工单标签页对成员显示之前，必须已为您的公司启用支持功能。

---

## 问题排查

### “成员找不到支持页面”

请确认已为您的公司启用 VTC 支持功能，并分享直接链接：`/vtc/@handle/support`。

### “我在管理面板中看不到支持标签页”

您至少需要 `support.view` 权限（或始终授予访问权限的 `management.vtc.edit` 权限）。

### “我无法编辑分类或模板”

编辑配置需要 `support.settings` 权限，该权限独立于工单处理权限。
