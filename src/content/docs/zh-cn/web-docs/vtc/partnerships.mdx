合作伙伴关系可将您的公司与其他 VTC 或 VBC 连接起来。合作伙伴会作为合作伙伴预览显示在您的公开资料上，从而为双方公司进行交叉推广。

合作伙伴关系不同于[姊妹公司](/zh-cn/web-docs/vtc/sister-companies/)（用于将 VTC 与拥有共享员工的 VBC 关联）和[合作 VTC 计划](/zh-cn/web-docs/vtc-programs/partnered/)（一项平台认可计划）。

## 访问合作伙伴关系

打开您公司的“管理”面板，然后从侧边栏中选择**合作伙伴关系**（`/vtc/@handle/manage/partnerships`）。

## 发送请求

1. 按名称或账号搜索您希望建立合作伙伴关系的公司。
2. 从搜索结果中选择该公司。
3. （可选）向该公司所有者撰写一条简短消息。
4. 发送请求。

目标公司的所有者将在其“合作伙伴关系”页面上审核该请求，并可选择接受或拒绝。

## 管理请求

“合作伙伴关系”页面包含三个列表：

| 列表 | 内容 |
|------|------|
| 收到的请求 | 其他公司发送给您的请求，等待您做出决定 |
| 已发送的请求 | 您已发送但尚未收到答复的请求 |
| 合作伙伴 | 您当前与之建立合作伙伴关系的公司 |

接受请求即可将该公司添加到您的合作伙伴列表。您可以随时拒绝或移除合作伙伴以终止合作关系。
