虚拟运输公司 (VTC) 或虚拟公交公司 (VBC) 是您的组织在 TrucklineMP 上的专属空间。本指南将介绍申请资格、创建向导以及公司上线后的相关操作。

## 开始之前

您需要：

- 已登录的 TrucklineMP 账户
- 创建 VTC/VBC 的权限（需符合平台资格规则）
- 当前未拥有同类型公司（每个账户只能拥有一家 VTC 和一家 VBC）

如需创建 VTC，请访问 [trucklinemp.com/vtc/create](https://trucklinemp.com/vtc/create)；如需创建 VBC，请访问 [trucklinemp.com/vbc/create](https://trucklinemp.com/vbc/create)。

---

## 资格检查

打开创建页面后，TrucklineMP 会自动进行资格检查。如果您不符合条件，页面会说明具体原因。常见原因包括：

- 已拥有所需类型（VTC 或 VBC）的公司
- 平台状态或限制（注意：创建公司没有账户最低使用时长要求）
- 平台配置禁用了该功能

您必须通过资格检查后才能继续。

---

## 创建向导

向导包含四个步骤：**身份**、**简介**、**可见性**和**审核**。

### 第 1 步：身份

| 字段 | 说明 |
|-------|-------|
| **公司名称** | 在平台上显示的名称。必填项。 |
| **简称** | 唯一的 URL 标识符：`trucklinemp.com/vtc/@yourhandle`（VTC）或 `trucklinemp.com/vbc/@yourhandle`（VBC）。长度为 2-15 个字符，仅可包含小写字母、数字和下划线。必填项。 |
| **口号** | 简短标语（可选）。 |
| **主要语言** | 公司的默认语言。 |
| **游戏** | 选择公司参与的游戏模拟器。至少需选择一项（ETS2 或 ATS）。 |
| **游戏内标签** | 游戏内使用的简短标签（例如 `TLP`，可选）。 |
| **总部城市 | 公司所在地的城市（）。 |
| **Logo** | 方形头像图片。可粘贴 HTTPS 图片链接或上传文件（JPEG、PNG 或 WebP 格式）。 |
| **横幅** | 宽幅封面图片。可粘贴 HTTPS 图片链接或上传文件。 |

### 第 2 步：简介

使用 Markdown 编写公司简介。必填项，最多 5,000 个字符。该简介将显示在您的公开资料页面上。

### 第 3 步：可见性

| 字段 | 说明 |
|-------|-------|
| **可见性** | 公开、不列出或私密。请参阅[可见性](/zh-cn/web-docs/vtc/visibility/)。 |
| **账户最低使用时长** | 申请前 TrucklineMP 账户必须满足的天数。设为 `0` 表示无限制。 |
| **最低游戏时长** | 申请前需达到的游戏时长（小时）。设为 `0` 表示无限制。 |
| **开放招募** | 创建后是否允许立即申请者提交申请。 |
| **联系邮箱** | 公开的可选联系邮箱地址。 |
| **社交链接** | 网站、Discord 邀请链接、Instagram、Facebook 和 X/Twitter。如果提供，必须为完整的 `https://` 链接。 |

### 第 4 步：审核

查看公司资料的实时预览，然后提交。提交成功后，您将跳转至新创建的公司资料页面。

---

## 默认设置

公司创建后，TrucklineMP 会预置以下角色：

- **管理层**
- **员工**
- **司机**（或 **司机/教练**，取决于 VTC/VBC 类型）
- **招募中**

您将成为拥有全部权限的所有者。从公司资料页面打开**管理**，即可配置招募、成员和 Discord 关联。

---

## 创建后操作

建议的后续步骤：

1. [常规设置](/zh-cn/web-docs/vtc/general-settings/) - 完善品牌信息和社交链接
2. [角色与权限](/zh-cn/web-docs/vtc/roles-permissions/) - 调整您的组织结构
3. [招募](/zh-cn/web-docs/vtc/recruitment/) - 开放申请或设置外部申请表
4. [Discord 验证](/zh-cn/web-docs/vtc/discord-verification/) - 关联您的 Discord 服务器（可选）

## 问题排查

### “没有资格创建公司”

请阅读创建页面上显示的原因。您可能已拥有同类型公司（VTC/VBC），或需要解决平台状态问题。

### 简称无法保存

简称必须为 2-15 个字符，仅可包含小写字母、数字和下划线，且必须唯一。

### 创建时社交链接提交失败

每个可选链接都必须以 `https://` 开头。Discord 邀请链接必须是完整 URL，不能仅使用邀请码。
