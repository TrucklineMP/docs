TrucklineMP 允许您控制谁能找到并访问您的虚拟运输公司。请选择适合您 VTC 定位的可见性级别。

## 可见性级别

每个 VTC 都有一个可见性设置，包含三个选项：

| 可见性 | 是否列于目录 | 是否可通过 URL 访问 | 谁可以查看 |
|-----------|---------------------|-------------------|--------------|
| **公开** | 是 | 是 | 所有人 |
| **不列出** | 否 | 是 | 所有拥有链接的人 |
| **私密** | 否 | 否 | 仅限成员和受邀用户 |

### 公开

公开 VTC 对 TrucklineMP 上的所有人可见。

- 会显示在 `trucklinemp.com/vtc` 的 VTC 目录中
- 会出现在搜索结果中
- 任何人都可以查看该资料
- 如果招募功能已开启，任何人都可以申请加入
- 最适合：希望公开发展并招募成员的成熟 VTC

### 不列出

不列出 VTC 不会出现在目录中，但通过直接链接即可访问。

- **不会**出现在 VTC 目录中
- **不会**出现在搜索结果中
- 任何拥有 URL 的人都可以查看该资料
- 适用于：测试、软发布，或通过直接链接实现自然增长的 VTC

### 私密

私密 VTC 完全隐藏，仅通过邀请加入。

- **不会**出现在 VTC 目录中
- **不会**出现在搜索结果中
- 只有成员才能查看资料
- 新成员必须通过邀请链接加入
- 最适合：封闭团体、内部团队，或希望完全控制成员资格的 VTC

## 如何更改可见性

### 创建 VTC 期间

创建新 VTC 时，可在创建表单中选择可见性选项：

1. 前往 `trucklinemp.com/vtc/create`
2. 填写您的 VTC 详细信息
3. 在**可见性**下选择公开、不列出或私密
4. 完成创建流程

### 通过 VTC 设置

创建后如需更改可见性：

1. 前往您的 VTC 管理面板
2. 选择**常规设置**
3. 滚动到**可见性**部分
4. 选择公开、不列出或私密
5. 点击**保存配置**

**注意：** 可见性更改会立即生效。

## 私密 VTC 的邀请

私密 VTC 需要邀请新成员才能加入。

### 创建邀请

1. 前往您的 VTC 管理面板
2. 从侧边栏选择**邀请**
3. 点击**创建邀请**
4. 配置邀请选项：
   - **最大使用次数** - 该链接可被使用的次数（留空表示不限次）
   - **过期时间（小时）** - 链接保持有效的时间（留空表示永不过期）
   - **目标用户（可选）** - 将邀请限制给特定用户
5. 点击**创建邀请**
6. 复制邀请链接并分享

### 邀请链接格式

```
https://trucklinemp.com/vtc/invite/YOUR_CODE
```

### 管理邀请

邀请页面会显示您所有的有效和已使用的邀请：

| 状态 | 含义 |
|--------|---------|
| **有效** | 链接仍可使用 |
| **已撤销** | 已被管理方手动禁用 |
| **已接受** | 已有用户通过此链接加入 |
| **已拒绝** | 已有用户拒绝了邀请 |
| **已过期** | 已超过有效期或使用次数上限 |

### 撤销邀请

点击任意有效邀请旁边的**撤销**，即可立即禁用该链接。被撤销的链接将无法再使用。

### 定向邀请

定向邀请仅限一个或多个特定的 TrucklineMP 用户：
- 只有被指定的用户才能接受邀请
- 用户必须使用正确的账户登录
- 适用于招募特定驾驶员

## 可见性与可搜索性

可见性控制谁能查看您的 VTC。而`可搜索`标志则控制您的 VTC 是否出现在目录列表和搜索结果中。

- **公开 + 可搜索** - 默认设置，会出现在所有地方
- **公开 + 不可搜索** - 拥有 URL 即可查看，但不会出现在列表中
- **不列出** - 自动不可搜索
- **私密** - 自动不可搜索

大多数情况下，您只需使用可见性设置即可。

## 不同可见性下的访问权限

| 操作 | 公开 | 不列出 | 私密 |
|--------|--------|----------|---------|
| 查看资料 | 任何人 | 拥有 URL 的任何人 | 仅限成员 |
| 在目录中可见 | 是 | 否 | 否 |
| 搜索可见 | 是 | 否 | 否 |
| 申请加入 | 是（若招募已开启） | 是（若招募已开启） | 否 |
| 通过邀请加入 | 否 | 否 | 是 |
| 查看活动 | 任何人 | 拥有 URL 的任何人 | 仅限成员 |
| 查看新闻 | 任何人 | 拥有 URL 的任何人 | 仅限成员 |

---

## 员工覆盖权限

拥有 `web.vtc.private.access` 权限的 TrucklineMP 员工可出于审核目的查看私密 VTC。但这并不会使他们成为该 VTC 的成员。

## 最佳实践

### 公开 VTC
- 保持资料完整且专业
- 在积极寻找成员时开启招募功能
- 及时回复申请
- 在准备就绪后再使用公开可见性

### 不列出 VTC
- 在目标社区中分享您的 URL
- 用于在公开前进行软发布
- 根据受众调整招募设置

### 私密 VTC
- 为特定用户创建定向邀请
- 设置合理的过期时间以确保安全
- 监控有效邀请并撤销未使用的邀请
- 使用最大使用次数来控制链接的传播范围

### 切换可见性

**公开 → 私密：** 现有成员资格保持不变。新成员必须通过邀请加入。

**私密 → 公开：** 任何人都可以找到并查看您的 VTC。请确保您的资料已准备就绪。

**不列出 → 公开：** 您的 VTC 将出现在目录和搜索结果中。

## 问题排查

### “我的 VTC 没有出现在目录中”
- 检查可见性是否设置为**公开**
- 如果您希望 VTC 出现在招募筛选结果中，请确认招募功能已开启
- 等待几分钟让缓存更新

### “人们无法加入我的私密 VTC”
- 确保您已创建有效的邀请
- 检查邀请是否已过期或使用次数已达上限
- 对于定向邀请，请确认用户已使用正确的账户登录

### “我的不列出 VTC 出现在了搜索结果中”
- 不列出 VTC 不应出现在搜索结果中
- 如果确实出现，请检查可见性是否未设置为公开
- 如果问题仍然存在，请联系支持团队

### “我无法访问受邀加入的私密 VTC”
- 确保您已登录
- 检查邀请链接是否已过期
- 对于定向邀请，请使用收到邀请的账户登录
