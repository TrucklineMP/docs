贵公司管理面板中的“集成”选项卡可创建嵌入令牌，用于在外部网站（例如贵 VTC 自己的网站或关联的社区页面）上展示即将举行的活动。

从侧边栏打开“管理”>“集成”（`/vtc/@handle/manage/integrations`）。拥有 `events.manage` 权限的工作人员可以创建和撤销令牌。

## 嵌入的工作原理

嵌入是一个 iframe 小部件，用于列出您即将举行的活动。该小部件由 TrucklineMP 提供，并会随着活动变更而自动更新。访客无需拥有账户即可查看该小部件。

## 创建嵌入令牌

1. 打开“集成”。
2. 点击“创建令牌”，为其指定一个标签，然后生成令牌。
3. 设置小部件应包含多少天内的即将举行的活动。
4. 复制生成的 iframe 代码片段，并将其粘贴到您的外部页面中。

## 撤销令牌

您可以随时在同一选项卡中撤销令牌。撤销令牌会立即停用所有使用该令牌的嵌入。

## 预览

“集成”选项卡会实时显示小部件的预览效果，方便您在复制代码片段前确认其外观。
