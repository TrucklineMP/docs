公司管理面板中的“成员活跃度”页面会显示每位成员的活跃程度，并允许工作人员管理不活跃政策及休假申请。请从侧边栏（`/vtc/@handle/manage/member-activity`）打开该页面。

访问此页面需要 `management.members.view_activity` 权限。公司所有者始终拥有访问权限。

## 活跃度状态

每位成员都有一个活跃度状态，该状态基于其近期的参与情况：

| 状态 | 含义 |
|--------|---------|
| 活跃 | 近期有参与 |
| 有风险 | 一段时间内未活跃，且即将达到不活跃阈值 |
| 不活跃 | 超过允许期限仍未活跃 |
| 休假中 | 已获批的休假申请覆盖中 |
| 豁免 | 免于活跃度要求 |

该页面会显示每位成员上次活跃距今的天数，以及他们在审核期间参与的活动数量。

## 不活跃政策

工作人员可以设置成员被标记为不活跃前所允许的最长不活跃天数。被标记为不活跃的成员可能会被移出公司，或可通过提交休假申请来保留其成员资格。

## 休假申请

成员若有一段时间无法参与，可以申请休假。工作人员会审核待处理的申请，并批准或拒绝。已批准的休假可使成员免受不活跃政策的影响，直至休假结束。
