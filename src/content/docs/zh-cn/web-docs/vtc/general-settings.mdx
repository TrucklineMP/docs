“常规设置”页面用于配置 VTC 的核心身份和公开形象。

## 访问常规设置

1. 前往您的 VTC 管理面板
2. 从侧边栏选择 **常规设置**
3. 您将看到“身份”、“要求”、“社交链接”和“Discord 服务器”等版块

---

## VTC 身份

### VTC 名称
- 您的 VTC 在平台各处可见的显示名称
- 必填字段
- 更改后会影响您的 VTC 在目录和个人资料中的显示方式

### VTC 标识符
- 您的 VTC URL 唯一标识符：`trucklinemp.com/vtc/@yourhandle`
- 最多 15 个字符
- 仅允许使用小写字母、数字和下划线
- 在界面中会以 `@` 前缀显示
- 更改后将永久改变您的 VTC URL

### 口号
- 显示在 VTC 个人资料上的简短标语
- 最多 60 个字符
- 显示在个人资料页顶部的 VTC 名称下方

### 简介
- 关于您 VTC 的富文本描述（支持 Markdown）
- 最多 5,000 个字符
- 必填字段
- 显示在您的 VTC 公开个人资料上
- 可借此讲述您的 VTC 故事、使命以及独特之处

### 规则
- 您的 VTC 规则与指南（支持 Markdown）
- 必填字段
- 成员和申请者均可查看
- 请确保内容清晰且全面

### 徽标
- 您的 VTC 个人资料图片 URL
- 必须是有效的 HTTPS URL
- 显示在目录、个人资料和动态中
- 建议：方形图片，至少 256x256 像素

### 横幅
- 您的 VTC 个人资料封面横幅 URL
- 必须是有效的 HTTPS URL
- 显示在 VTC 个人资料页面顶部
- 建议：宽幅图片，至少 1920x400 像素

## 要求与招募

配置谁可以加入您的 VTC 以及招募机制。

### 最低账户年龄
- 设置申请加入所需的 TrucklineMP 账户最低年龄（单位：天）
- 有助于筛选新注册的账户
- 设为 0 表示接受任何年龄的账户

### 最低游戏时长
- 设置申请加入所需的最低游戏时长（单位：小时）
- 确保申请者具备游戏经验
- 设为 0 表示接受任何游戏时长的申请者

### 主要语言
- 您的 VTC 主要语言
- 可从支持的语言列表中任选
- 显示在您的 VTC 个人资料上
- 帮助用户找到符合其语言需求的 VTC

### 开放招募
- 切换以启用或禁用招募功能
- 启用时，您的 VTC 在目录中显示为“正在招募”
- 禁用时，您的 VTC 显示为“已关闭”
- 此设置不影响现有成员

## 社交与形象

添加您 VTC 的在线形象链接。所有 URL 都必须是有效的 `https://` 链接。

### Discord 邀请链接
- 您的 VTC Discord 服务器链接
- 如可使用永久邀请链接
- 显示在您的 VTC 个人资料上

### 网站 URL
- 您的 VTC 官方网站
- 显示在您的 VTC 个人资料上
- 必须是有效的 HTTPS URL

### 公开邮箱
- 您的 VTC 联系邮箱
- 在个人资料上公开显示
- 必须是有效的电子邮件地址

### Instagram
- 您的 VTC Instagram 个人主页链接
- 必须是有效的 HTTPS URL

### Twitter/X
- 您的 VTC Twitter 或 X 个人主页链接
- 必须是有效的 HTTPS URL

### Facebook
- 您的 VTC Facebook 页面链接
- 必须是有效的 HTTPS URL

## 保存更改

- 点击右下角的 **保存配置** 以应用更改
- 滚动页面时会出现一个浮动保存按钮
- 更改将立即生效
- 保存成功后您将看到成功提示通知

---

## 最佳实践

### 完善个人资料
- 填写所有字段以展现专业形象
- 为徽标和横幅使用高质量图片
- 撰写引人入胜的简介，讲述您的故事
- 确保规则清晰且全面

### URL
- 尽可能使用永久链接
- 保存后测试所有链接
- 仅使用 HTTPS URL

### 招募设置
- 设置合理的要求以筛选申请者
- 在积极招募期间保持招募功能开启
- 更新语言设置以匹配您的社区

---

## 问题排查

### “我无法保存更改”
- 确保所有必填字段（名称、简介、规则）均已填写
- 检查所有 URL 是否为有效的 HTTPS 链接
- 验证邮箱格式是否正确

### “我的图片无法显示”
- 确保 URL 可被公开访问
- 使用直接指向图片的链接（而非页面链接）
- 检查 URL 是否以 `https://` 开头

### “我想更改我的 VTC 标识符”
- 标识符可在“常规设置”中更改
- 此操作会更改您的 VTC URL
- 旧 URL 不会自动跳转
