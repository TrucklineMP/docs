公司管理面板中的“外观设置”页面用于控制您公司公开页面的显示效果。该页面包含两个部分：主题编辑器和主页布局构建器。

从侧边栏打开“外观设置”页面（路径：`/vtc/@handle/manage/appearance`）。需要 `management.vtc.appearance` 权限。公司所有者始终拥有访问权限。

## 主题编辑器

主题编辑器用于设置公司页面中使用的强调色、背景色和文本色。在保存更改前，您可以实时预览效果。

高级主题选项对大多数公司处于锁定状态。同时拥有“认证”和“合作”身份的公司可解锁这些选项。

为确保文本在页面上清晰可读，所有颜色在保存前都必须通过可读性对比度检查。

## 主页布局构建器

主页布局构建器可重新排列您公司公开页面上显示的版块。您可以添加、移动、调整大小或移除概览、规则、成员、活动、新闻、图库或招聘等版块。

仅可访问自定义页面布局的公司才能使用此布局功能。有关资格要求，请参阅[认证 VTC 计划](/zh-cn/web-docs/vtc-programs/verified/)和[合作 VTC 计划](/zh-cn/web-docs/vtc-programs/partnered/)。
