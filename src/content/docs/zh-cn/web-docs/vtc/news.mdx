VTC 新闻功能可让您的公司在 TrucklineMP 个人资料上发布动态。这些帖子会显示在您的 VTC 新闻源中，并可能通过全局新闻 API 展示给公开读者。

## 访问新闻管理

1. 打开您的 VTC **管理**面板
2. 从侧边栏选择 **新闻**（`/vtc/@handle/manage/news`）
3. 在新闻仪表盘中创建、编辑或删除帖子

您的 VTC 角色需要拥有 `news` 权限（例如 `news.create`、`news.edit`、`news.delete`）。所有者拥有完整访问权限。

---

## 创建帖子

点击 **新建帖子** 并提供以下信息：

| 字段 | 说明 |
|-------|-------|
| **标题** | 显示在新闻源和帖子页面上的标题 |
| **内容** | Markdown 格式正文 |
| **封面图片** | 可选的 HTTPS 横幅图片 |
| **置顶** | 将此帖子固定在新闻源顶部 |

保存后即可立即发布。编辑操作会实时更新已发布的帖子。

---

## 公开可见性

已发布的帖子会出现在以下位置：

- 您的 VTC 个人资料新闻标签页
- 单个帖子页面（`/vtc/@handle/post/{postId}`）
- 公共 API 的 `GET /vtcs/{id}/news` 和 `GET /news/{newsId}` 接口

未列出或私密的 VTC 可见性规则仍适用于访问您个人资料的用户。

---

## 置顶帖子

将重要公告（如招聘活动、政策变更、活动提醒）置顶，使其始终显示在较旧的帖子之上。建议只置顶一个或少数几个帖子，以保持新闻源的可读性。

---

## 删除帖子

删除操作不可逆。具有删除权限的工作人员可通过管理面板移除帖子。如需修正细微错误，建议优先选择编辑而非删除。

---

## 公告集成

如果您使用 [VTC 公告](/zh-cn/web-docs/vtc/announcements/) 的 Discord webhook，新闻事件（发布、更新）可通过占位符（如 `{news.title}`）触发自动 Discord 消息。

---

## 工作人员审核

平台工作人员可能会对违反规则的 VTC 新闻进行审核。在适用情况下，VTC 所有者可在管理面板中查看审核状态。

---

## 最佳实践

- 使用清晰的标题，以便成员快速浏览新闻源
- 仅置顶当前重要的内容
- 在相关时链接到 [活动](/zh-cn/web-docs/vtc/events/) 或招聘页面
- 确保图片使用您可控的 HTTPS 链接
