合作 VTC 计划旨在表彰在 TrucklineMP 社区中已建立稳固影响力并拥有良好声誉的优秀虚拟运输公司。合作 VTC 将获得紫色合作者徽章、平台内更高的曝光度，以及专属权益，包括定制游戏内卡车涂装。

## 资格要求

如需申请合作身份，您的 VTC 必须满足以下标准：

### 强制性要求
- **认证身份：** 您的 VTC 必须已在 [认证 VTC 计划](/zh-cn/web-docs/vtc-programs/verified/) 中获得认证身份。
- **活跃成员：** 您的 VTC 必须拥有至少 **50 名活跃成员**（过去 30 天内有参与记录）。
- **运营时长：** 您的 VTC 必须在 TrucklineMP 上运营至少 **6 个月**。
- **良好记录：** 您的 VTC 近期不得有任何违反 TrucklineMP 规则或服务条款的行为。
- **专业形象：** 您的 VTC 必须维护以下要素：
  - 完整且专业的 VTC 资料页（位于 TrucklineMP 上）。
  - 活跃的 Discord 服务器或同等功能的社区平台。
  - 面向公众的网站或社交媒体账号。
  - 清晰易懂的 VTC 规则与指南。

### 质量标准
- **定期活动：** 您的 VTC 必须通过以下方式展现持续活跃度：
  - 定期组织车队、活动或运营任务。
  - 积极招募成员并促进成员互动。
  - 与成员保持常态化沟通。
- **社区声誉：** 您的 VTC 必须在 TrucklineMP 社区中享有良好声誉，且不得有以下行为记录：
  - 骚扰或传播负面情绪。
  - 欺诈行为。
  - 与其他 VTC 或 TrucklineMP 团队发生冲突。
- **管理层稳定性：** 您的 VTC 必须拥有稳定且负责任的管理团队，并能及时回应管理团队的问询。

## 申请流程

合作身份仅通过 **邀请制** 或 **人工审核申请** 产生，其流程与认证 VTC 计划不同。

### 申请步骤
1. **确认资格：** 核实您的 VTC 是否满足上述所有强制性要求。
2. **准备材料：** 整理以下信息：
   - VTC 发展历程与成就。
   - 成员统计数据与活跃度指标。
   - VTC 网站、Discord 及社交媒体链接。
   - 社区贡献或合作案例示例。
3. **提交申请：** 通过以下方式联系 Truckline 管理团队：
   - **Discord：** 在 [https://discord.gg/trucklinemp](https://discord.gg/trucklinemp) 中提交工单。
   - **电子邮件：** partnerships@trucklinemp.com
4. **审核流程：** 您的申请将由 Truckline 管理团队审核，耗时约 **2-4 周**，具体取决于申请数量。
5. **结果通知：** 您将通过首选联系方式收到审核结果通知。

### 邀请机制
Truckline 团队可能会向展现出卓越品质与社区贡献的 VTC 发出合作邀请。此类邀请由团队酌情决定，无需正式申请。

## 合作身份权益

合作 VTC 除享有所有认证 VTC 权益外，还可获得以下额外福利：

| 权益 | 标准 VTC | 认证 VTC | 合作 VTC |
|---------|-------------|--------------|---------------|
| 认证徽章 | 无 | 有（蓝色） | 有（蓝色） |
| 合作者徽章 | 无 | 无 | 有（紫色） |
| 自定义角色 | 最多 20 个 | 无限制 | 无限制 |
| 目录曝光度 | 标准 | 高亮 | **推荐展示** |
| 自定义页面布局 | 无 | **有** | 有 |
| 页面主题定制 | 无 | 无 | **有** |
| 活动优先权 | 标准 | 标准 | **优先安排** |
| 内测成员招募 | 标准 | 优先 | **优先招募** |
| 资料页徽章 | 无 | 蓝色“已认证” | 紫色“已合作”+ 蓝色“已认证” |
| 支持渠道 | 标准 | 标准 | **专属支持** |
| 合作机会 | 无 | 无 | **官方合作** |
| 定制游戏内涂装 | 无 | 无 | **有（需经 staff 批准）** |

### 合作者徽章
- 紫色“已合作”徽章将 prominently 展示于您的 VTC 资料页。
- 该徽章将与您的认证徽章并列显示，彰显您的精英身份。
- 描述文字为：“该 VTC 是 Truckline 认可的合作方。”

### 目录推荐展示
- 合作 VTC 将在 VTC 目录顶部获得推荐展示。
- 您的 VTC 在搜索结果与推荐列表中的曝光度将显著提升。

### 活动优先权
- 合作 VTC 在官方活动与合作项目中享有优先参与权。
- 您的活动可能会被收录于全局动态 feed 及宣传材料中。

### 内测成员优先招募
- 合作 VTC 的所有成员在申请 TrucklineMP 内测资格时均享有 **优先权**。
- 此权益同样适用于认证 VTC，但合作 VTC 可因其精英身份持续享有该权益。
- 优先权适用于 VTC 内所有成员，而不仅是管理层。
- 成员仍需完成内测 NDA 验证流程。
- 当成员使用其关联的 Discord 账户接受 NDA 时，优先状态将自动生效。

### 专属支持
- 合作 VTC 可使用专属支持渠道处理紧急问题。
- 管理团队将更快地响应您的审核与技术支持请求。

### 合作机会
- 合作 VTC 可能被邀请参与以下项目：
  - TrucklineMP 官方活动与车队任务。
  - 与其他合作 VTC 的联合推广活动。
  - 平台新功能的内测。
  - 社区大使计划。

### 定制游戏内涂装
- 合作 VTC 可申请 **定制游戏内卡车涂装**，以展示其 VTC 品牌特色。
- 您可选择设计方案，Truckline 团队将在 staff 审核批准后将其实装至游戏中。
- 所有涂装均须符合 [VTC 涂装指南](/zh-cn/web-docs/vtc-programs/livery-guidelines/)。
- 该涂装为合作权益，标准 VTC 或认证 VTC 除非另行授权，否则不可使用。
- 如需申请或更新涂装，请通过 Discord 或 **partnerships@trucklinemp.com** 联系合作团队，并提交您的设计素材与 VTC 详细信息。

### 页面主题定制
- 合作 VTC 可通过管理面板的 **外观** → **主题** 选项 **自定义 VTC 页面主题**。
- 您可根据 VTC 品牌调整强调色、背景与文字颜色。
- 所选颜色必须通过可读性对比度检测后方可保存。
- 需具备 `management.vtc.appearance` 或 `management.vtc.edit` 权限。

合作 VTC 还可继承所有 [认证 VTC 权益](/zh-cn/web-docs/vtc-programs/verified/#已验证状态的优势)，包括自定义页面布局与资料页版块。

## 维持合作身份的规则

合作身份是一项特权，需持续符合更高标准。

### 持续要求
1. **保持认证身份：** 您必须继续遵守认证 VTC 计划的所有规则。
2. **维持活跃度：** 您的 VTC 必须保持至少 **50 名活跃成员**，并展现持续活跃度。
3. **遵守社区规范：** 您的 VTC 必须维持良好声誉与专业形象。
4. **及时回应问询：** 管理层必须在 **48 小时** 内回应 Truckline 团队的问询。
5. **参与社区活动：** 合作 VTC 应每季度至少参与 **一项 TrucklineMP 官方活动**（如有举办）。
6. **保持涂装合规：** 若您的 VTC 拥有定制游戏内涂装，该涂装必须持续符合 [VTC 涂装指南](/zh-cn/web-docs/vtc-programs/livery-guidelines/)。staff 可要求修改或移除违规涂装。
7. **禁止使用 AI 生成内容：** 合作 VTC 必须遵守 [认证 VTC 计划中关于禁止使用 AI 生成内容的规定](/zh-cn/web-docs/vtc-programs/verified/#禁止使用-ai-生成的媒体内容)。认证与合作 VTC 均不得在其 VTC 页面或官方品牌中使用 AI 生成的头像、横幅、网站内容或其他 AI 生成媒体。

### 禁止行为
以下行为可能导致合作身份被立即撤销：
- 违反 TrucklineMP 服务条款或社区规范。
- 实施骚扰、仇恨言论或歧视行为。
- 因违规而失去认证身份。
- 无法维持最低活跃度或成员数量要求。
- 虚假宣传合作身份或将其用于未经授权的用途。
- 未在规定时限内回应管理团队问询。
- 未经授权使用合作身份进行商业牟利。
- 提交或保留违反 [VTC 涂装指南](/zh-cn/web-docs/vtc-programs/livery-guidelines/) 的定制涂装。
- 在 VTC 页面或官方品牌中使用 AI 生成的头像、横幅、网站内容或其他 AI 生成媒体。

### 身份撤销
- 若您的 VTC 未能遵守上述规则，Truckline 管理团队可随时撤销其合作身份。
- 合作身份被撤销后，若仍符合认证资格，您的 VTC 可保留认证身份，但须重新申请合作身份。
- 身份撤销并非永久决定，但您必须在解决问题并重新满足所有资格要求后方可再次申请。

### 审核流程
- 合作 VTC 将接受 **定期审核**（每 6-12 个月一次），以确保持续符合计划标准。
- 审核将评估活跃度、社区声誉及规则遵守情况。
- 审核未通过的 VTC 可能会被处以观察期，或合作身份将被撤销。

## 常见问题

### 成为合作 VTC 需要多长时间？
完整申请的审核流程通常需要 2-4 周。但合作身份无法保证获批，部分申请可能需要额外审核时间。

### 未获得认证是否可以申请合作身份？
不可以。您的 VTC 必须先获得认证身份，才能申请合作身份。

### 合作身份需要付费吗？
不需要。合作 VTC 计划对所有符合条件的 VTC 免费开放。

### 我会失去合作身份吗？
会。若违反 TrucklineMP 规则、无法维持活跃度或存在其他违规行为，合作身份可能被撤销。

### 若我的 VTC 成员数降至 50 名以下会怎样？
您将获得 **30 天宽限期** 以恢复成员数量。若宽限期内 VTC 活跃成员数仍低于 50 名，合作身份可能被撤销。

### 合作 VTC 之间可以合作吗？
可以。我们鼓励合作 VTC 共同组织活动、车队任务及社区项目。Truckline 团队可协助促成合作并提供支持。

### 合作 VTC 能获得经济报酬吗？
不能。合作身份是对 VTC 品质与社区贡献的认可，而非经济奖励。但合作 VTC 可享受专属权益与机会。

### 合作 VTC 可以定制游戏内涂装吗？
可以。合作 VTC 可申请定制游戏内卡车涂装，但须经 staff 批准并符合 [VTC 涂装指南](/zh-cn/web-docs/vtc-programs/livery-guidelines/)。请联系合作团队提交设计方案或提出修改请求。
