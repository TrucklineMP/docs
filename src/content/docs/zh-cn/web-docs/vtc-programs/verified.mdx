已验证 VTC 计划旨在认可 TrucklineMP 平台上真实、活跃且管理良好的虚拟运输公司。已验证 VTC 将获得蓝色验证徽章，并可使用额外的平台功能。

## 如何申请

### 资格

- 您必须是 VTC 的**所有者**或拥有 `management.vtc.edit` 权限。
- 您的 VTC **不得**已被验证。
- 已验证 VTC 计划必须**当前接受申请**（请在您 VTC 的“验证状态”页面查看状态）。

### 申请流程

1. 前往您 VTC 的管理面板。
2. 从侧边栏选择**验证状态**。
3. 阅读页面上显示的计划要求。
4. 点击**申请验证**以打开申请表。
5. 准确填写所有必填问题。
6. （可选）提供 Discord webhook URL，以便接收状态通知。
7. 提交您的申请。

### 提交后

- 您的申请将进入**待审核**状态。
- Truckline 审核团队将对您的申请进行审核。
- 在评估期间，您的状态可能变为**审核中**。
- 您将通过以下方式收到审核结果通知：
  - 您 VTC 的“验证状态”页面上显示的状态。
  - Discord webhook 通知（如果已提供）。

### 重新申请

- 如果您的申请被**拒绝**，您必须等待 **30 天**后才能重新申请。
- 如果您的申请被**撤回**，您可以立即提交新的申请。

### 撤回申请

- 在申请处于**待审核**或**审核中**状态时，您可以随时撤回申请。
- 撤回的申请可以立即通过新的申请替代。

## 要求

您的 VTC 必须满足以下要求才能获得验证批准：

### 一般要求

- 您的 VTC 必须是一个**真实且活跃**的虚拟运输社区。
- 您的 VTC 必须拥有**完整的资料**，包括：
  - 有效的 VTC 名称和标识。
  - 简介或口号。
  - 联系信息（网站、电子邮件、Discord 或社交媒体）。
- 您的 VTC 必须遵守所有 <a href={LEGAL_URLS.termsOfService}>TrucklineMP 服务条款</a>和社区准则。

### 跨平台会员资格

如果您的 VTC 在另一个虚拟运输平台（例如 TruckersMP）上拥有活跃资料，则该**外部**名单中的一部分司机也必须是您 TrucklineMP VTC 的成员。所需的重叠比例随外部名单规模扩大而增加——规模较大的社区需要在此平台上有更强的存在感。

当您申请中提及或关联了一个或多个外部资料（例如 TruckersMP VTC 页面 URL）时，此要求适用。如果您**没有**外部 VTC 资料，则本节不适用。

#### 重叠等级

请使用与您**最大的已披露外部 VTC 名单的司机数量**相匹配的行。您必须同时满足该等级的百分比要求和最低绝对人数要求（以两者中要求人数较多者为准）。

| 外部司机数 | TrucklineMP 上所需的重叠人数 |
|------------|-------------------------------|
| **1-19**   | 至少 **8** 名成员             |
| **20-49**  | 至少 **25%**，最低 **12** 名成员 |
| **50-99**  | 至少 **30%**，最低 **18** 名成员 |
| **100-199**| 至少 **35%**，最低 **40** 名成员 |
| **200-399**| 至少 **40%**，最低 **90** 名成员 |
| **400+**   | 至少 **45%**，最低 **160** 名成员 |

**示例**

- TruckersMP 上有 15 名司机 → 需要在 TrucklineMP 上有 **8** 名。
- TruckersMP 上有 40 名司机 → 25% = 10，但该等级的最低要求为 **12** → 需要在 TrucklineMP 上有 **12** 名。
- TruckersMP 上有 80 名司机 → 30% = **24** 名 TrucklineMP 成员。
- TruckersMP 上有 150 名司机 → 35% = **53** 名 TrucklineMP 成员。
- TruckersMP 上有 350 名司机 → 40% = **140** 名 TrucklineMP 成员。

百分比将**向上取整**到最近的完整司机数。重叠人数以您披露的外部名单中的成员为准——审核时可能会排除不活跃或重复的成员。

#### 申请时

- 您必须在**申请时**满足您外部名单规模对应的等级要求。
- 重叠人数未达要求的应用可能会被拒绝，直到您的 TrucklineMP 会员数量跟上为止。

#### 验证后

- 您应保持在所属等级内。如果您的会员数量持续**低于您所在等级要求百分比 10 个百分点以上**，或低于该等级的最低人数要求，可能会触发审核，并影响您的已验证状态。
- 短期波动（例如在另一平台完成招募活动后）属于正常现象；如果您预计会出现临时变化，请联系工作人员。

### 申请问题

申请表包含由 Truckline 团队配置的问题，可能包括：

- 您 VTC 的 TruckersMP 页面 URL（如适用）。
- 关于您 VTC 结构、规则和活动的详细信息。
- 您 VTC 的 Discord 服务器或网站链接。
- 用于接收验证状态通知的 Discord webhook URL。

**所有必填字段都必须如实填写。**不完整或具有误导性的申请将被拒绝。

## 已验证状态的优势

已验证 VTC 可享受以下优势：

| 优势                 | 标准 VTC | 已验证 VTC             |
|----------------------|----------|------------------------|
| 验证徽章             | 否       | 是（蓝色对勾）         |
| 自定义角色           | 最多 20 个 | **无限制**             |
| 目录可见性           | 标准     | 使用徽章突出显示       |
| 个人资料徽章         | 无       | 蓝色“已验证”标识       |
| 自定义页面布局       | 否       | **是**                 |
| 社区信任度           | 标准     | 增强可信度             |
| 内测人员招募         | 标准     | **优先招募**           |

### 验证徽章

- 一个蓝色对勾徽章将显示在您 VTC 名称的旁边，贯穿整个平台。
- 该徽章会出现在您的 VTC 个人资料、VTC 目录以及全局动态中。

### 无限制自定义角色

- 已验证 VTC 可以为其组织层级创建**无限制数量的自定义角色**。
- 标准 VTC 的角色上限为 20 个。

### 增强可见性

- 已验证 VTC 在 VTC 目录中会以蓝色“已验证”徽章突出显示。
- 您的 VTC 个人资料将显示一个醒目的“已验证”标识，并附有说明：_“该 VTC 已通过真实性验证。”_

### 优先内测人员招募

- 所有已验证 VTC 的成员在申请成为 TrucklineMP 内测人员时，都将获得**优先状态**。
- 此优先权适用于您 VTC 的每一位成员，而不仅仅是管理人员。
- 成员仍需完成内测保密协议（NDA）验证流程。
- 当成员使用其关联的 Discord 账户接受内测 NDA 时，优先状态将自动生效。

### 自定义页面布局和版块

- 已验证 VTC 可以使用“主页布局”构建工具**重新排列其 VTC 页面的网站内容**。
- 您可以**添加自定义个人资料版块**，以展示您的社区、规则、招募信息或其他内容。
- 请通过 VTC 管理面板的**外观**→**个人资料版块**和**主页布局**进行管理（需要 `management.vtc.appearance` 权限）。

## 维持已验证状态的规则

您的 VTC 获得验证后，必须持续遵守以下规则以维持其状态。

### 合规要求

1. **遵守所有 TrucklineMP 规则和政策。**任何违规行为都可能导致立即取消已验证状态。
2. **保持 VTC 资料的准确性和时效性。**这包括：
   - 有效且活跃的联系渠道（网站、Discord 或电子邮件）。
   - 准确无误的 VTC 信息和简介。
3. **不得参与欺诈或欺骗行为。**这包括：
   - 伪造会员数量。
   - 冒充其他 VTC 或组织。
   - 歪曲您 VTC 的活动或隶属关系。
4. **保持 VTC 的活跃运营。**已验证 VTC 如果变得不活跃或被遗弃，其状态可能会被撤销。
5. **不得使用 AI 生成的媒体内容。**已验证 VTC 不得将 AI 生成的内容用于其在 TrucklineMP 上的官方 VTC 形象（见下文）。

### 禁止使用 AI 生成的媒体内容

已验证 VTC（以及合作 VTC）**不得**在 TrucklineMP 上的公开 VTC 形象中使用 AI 生成的内容。该禁令包括但不限于：

- AI 生成的个人资料图片
- AI 生成的横幅
- 作为您 VTC 官方站点展示的 AI 生成的网站内容或着陆页
- 任何其他用于您 VTC 个人资料、页面版块或品牌标识的 AI 生成的图片、视频或媒体

使用 AI 生成的媒体可能导致已验证或合作状态被取消，并要求您替换相关资产。

### 禁止行为

以下行为可能导致立即取消已验证状态：

- 违反 TrucklineMP 服务条款。
- 参与骚扰、仇恨言论或歧视行为。
- 将 VTC 用于非法活动。
- 在 VTC 个人资料或申请中提供虚假信息。
- 将 VTC 所有权转移给不符合资格的用户。
- 在合理时间内未回复审核团队的问询。
- 在您的 VTC 页面或官方品牌标识中使用 AI 生成的个人资料图片、横幅、网站内容或其他 AI 生成的媒体。

### 状态撤销

- 如果您的 VTC 未能遵守这些规则，Truckline 审核团队可随时撤销其已验证状态。
- 如果您的已验证状态被撤销，您可以在解决导致撤销的问题后重新申请。
- 撤销对于当前的申请周期是永久性的。您必须在撤销后提交新的申请。

### 名称变更限制

- 已验证 VTC 的名称变更会受到冷却期限制，以防止滥用。
- 频繁或可疑的名称变更可能会触发对您已验证状态的审核。

## 申请状态

| 状态             | 描述                                                          |
| ------------------ | -------------------------------------------------------------------- |
| **待审核**       | 您的申请正在等待审核团队审核。                                   |
| **审核中**       | 您的申请正在被评估。                                             |
| **已批准**       | 您的 VTC 已获得验证状态。                                         |
| **未批准**       | 您的申请未被批准。您可以在 30 天后重新申请。                     |
| **已撤回**       | 您已撤回申请。您可以立即提交新的申请。                           |

## 常见问题

### 审核过程需要多长时间？

审核时间因申请量而异。大多数申请会在 7-14 天内完成审核。

### 提交申请后可以修改吗？

不可以。提交后，您无法修改申请。如需更改，请撤回当前申请并提交新的申请。

### 如果申请被拒绝会怎么样？

您将收到一封说明拒绝原因的审核通知。您可以在 30 天后重新申请。

### 可以对拒绝结果提出申诉吗？

没有正式的申诉流程。但是，您可以在 30 天的冷却期后，附上补充信息或更正内容，提交新的申请。

### 已验证状态会过期吗？

已验证状态没有固定的有效期。但是，如果您的 VTC 未能遵守计划规则或变得不活跃，该状态可能会被撤销。

### 我会失去已验证状态吗？

会。如果违反 TrucklineMP 规则、存在欺诈行为或长期不活跃，已验证状态可能会被撤销。

### 已验证状态需要付费吗？

不需要。已验证 VTC 计划对所有符合条件的 VTC 免费开放。

### 已验证 VTC 的所有者可以在主 Discord 中获得角色吗？

可以。您的 VTC 获得验证后，您可以在官方 TrucklineMP Discord 中申请**已验证 VTC 管理员/所有者**角色。请参阅 [已验证 VTC Discord 角色](/zh-cn/web-docs/vtc-programs/discord-role/)。
