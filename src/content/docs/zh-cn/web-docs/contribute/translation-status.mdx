本页面展示了哪些文档页面已翻译，以及各翻译的更新状态。每个单元格显示了文档版本及其最后更新日期。绿色状态表示翻译与英文版本一致；橙色表示翻译已落后；红色表示尚未翻译。

<TranslationStatusTable />

## 图例

- **当前** - 翻译版本与英文页面相同
- **过时** - 翻译版本低于英文页面（或若未设置版本，则根据日期判断已落后超过 1 天）
- **缺失** - 该语言尚无对应翻译

当英文页面的内容发生重大变化时，其 `version` 会随之提升。翻译人员更新翻译后，需将翻译版本的 `version` 设置为与英文页面一致，这样才表示翻译已再次保持同步。

## 如何参与

如果您发现翻译已过时，或希望贡献新的翻译，请：

1. 查阅《[贡献翻译指南](/zh-cn/web-docs/contribute/contributing/)》
2. 在 GitHub 上提交包含您翻译内容的拉取请求
3. 遵循指南中列出的文件结构和质量标准

感谢您帮助我们让文档在多种语言中保持可访问！
