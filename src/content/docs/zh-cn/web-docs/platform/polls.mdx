社区投票功能让社区成员可以对平台问题、活动创意及其他话题进行投票。请访问 [trucklinemp.com/polls](https://trucklinemp.com/polls) 查看当前开放的投票。

## 投票

投票需要登录账户。每个投票都会显示其问题、选项、截止时间以及结果是否公开。

部分投票仅限支持者参与。支持者可参与的投票会在投票页面进行标注。

## 结果

投票结束后结果将会开放，若投票设置允许，结果也可能提前开放。投票结果将根据投票设置进行分享。
