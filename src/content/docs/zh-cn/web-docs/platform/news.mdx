TrucklineMP 会发布有关平台、活动和社区动态的官方新闻。新闻内容公开，无需账户即可阅读。

## 阅读新闻

打开 [trucklinemp.com/news](https://trucklinemp.com/news) 即可浏览最新文章。文章按“常规”“平台”“社区”“开发”或“活动”等类别分组，您也可以通过页面顶部的筛选器进行筛选。

## 单篇文章

打开任意文章即可阅读全文。文章支持富文本格式、图片和链接。置顶文章将始终显示在信息流顶部，直到被取消置顶。

## 互动

已登录的用户可以对新闻文章进行互动。互动是表达对文章支持或反馈的快捷方式。

## 相关指南

- [通知](/zh-cn/web-docs/account/notifications/) - 接收有关新新闻的提醒
- [公共 API](/zh-cn/web-api/public-api/) - 通过 API 读取新闻
- [VTC 新闻](/zh-cn/web-docs/vtc/news/) - 由各公司发布的新闻
