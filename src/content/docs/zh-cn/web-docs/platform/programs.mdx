TrucklineMP 运营着多个社区项目，旨在表彰玩家和公司对平台的贡献。这些项目包括“漏洞猎人”项目、“贡献者”项目以及荣誉奖项。

## 项目

请访问 [trucklinemp.com/programs](https://trucklinemp.com/programs)，查看当前有效的项目及其详细信息。

每个项目页面都会介绍该项目的具体内容、参与方式以及可获得的荣誉奖励。

## 漏洞猎人

“漏洞猎人”项目旨在奖励通过支持系统发现并报告漏洞的玩家。团队会对提交的漏洞报告进行审核，经核实的漏洞将获得荣誉奖励。

## 贡献者

“贡献者”项目旨在表彰为平台或其文档做出贡献的个人。贡献者将被收录在[贡献者](/zh-cn/web-docs/contribute/contributors/)页面，并可能获得徽章。

## 荣誉

荣誉奖项用于表彰对社区做出杰出贡献的个人。荣誉由团队授予，并会显示在您的公开个人资料中。

## 相关指南

- [公开个人资料](/zh-cn/web-docs/account/public-profile/) - 徽章和荣誉将显示在此处
- [贡献者](/zh-cn/web-docs/contribute/contributors/) - 查看文档的贡献者名单
- [公开 API](/zh-cn/web-api/public-api/) - 通过 API 读取徽章数据
