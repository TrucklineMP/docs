TrucklineMP 会发布实时的服务状态和平台更新的公开更新日志。这两项内容均对公众开放，无需账户即可访问。

## 服务状态

打开 [trucklinemp.com/status](https://trucklinemp.com/status) 即可查看平台服务器和服务的当前状态。该页面会实时报告所列各项服务的状态。

如果您发现某些服务似乎对所有用户都不可用，请在提交支持请求前，先查看状态页面。

## 更新日志

打开 [trucklinemp.com/changelog](https://trucklinemp.com/changelog) 即可阅读已发布的版本说明。每条记录均包含：

- 分类（例如平台、社区或活动）
- 发布日期
- 适用时的版本信息
- 变更摘要

记录按时间倒序排列，最新的条目在最上方。
