TrucklineMP 运营着一个**官方 Discord 社区**，该社区独立于 VTC 拥有的服务器。官方服务器使用的机器人堆栈与用于 VTC 服务器和已关联角色的公共 **TrucklineMP 机器人**不同。

您可以通过 [trucklinemp.com](https://trucklinemp.com) 上的邀请链接或 Discord 发现功能加入。

---

## 两个机器人，两种职责

| 机器人 | 所在位置 | 职责 |
|-----|-------|------|
| **TrucklineMP 机器人** (DiscordBot) | VTC 和公共服务器 | 已关联角色、`/profile`、`/verify-server`、通知私信、VTC `/vtc` |
| **Modbot** | 官方主服务器、员工服务器和测试服务器 | 审核、工单、招募引导、日志记录 |

请勿在官方服务器上尝试对您的 VTC 使用 `/verify-server`。请在**您自己的** VTC Discord 中完成验证。

---

## 网站支持与 Discord 工单

| 需求 | 前往位置 |
|------|-------------|
| 封禁申诉 | [trucklinemp.com/support?lane=appeal](/zh-cn/web-docs/account/bans-appeals/) |
| 账户问题 | 网站上的[支持工单](/zh-cn/web-docs/account/support-tickets/) |
| 玩家举报（平台） | 网站支持或个人资料举报 |
| Discord 专属聊天审核 | 官方服务器的工单面板（在 Discord 内） |

Modbot 可能会引导您前往网站进行申诉。针对平台封禁，**网站申诉具有最终效力**。

---

## 招募与员工引导

员工招募流程在申请表被招募门户接受后，通过官方 Discord 进行。流程可能包括：

- 加入主公会
- 在网站上完成测试版保密协议验证
- 通过自动化引导分配角色

候选人应严格按照私信和频道中的说明操作。

---

## 官方服务器上的已关联角色

官方服务器可能会为已验证的成员或员工使用 TrucklineMP 已关联角色。设置方式与任何其他服务器相同：[已关联角色](/zh-cn/web-docs/discord-bot/linked-roles/)。

---

## VTC 服务器独立运营

VTC Discord 服务器由 VTC 所有者运营。除非通过[支持](/zh-cn/web-docs/account/support-tickets/)渠道报告平台规则违规行为，否则 TrucklineMP 员工不会审核 VTC 服务器。

请通过 [VTC Discord 验证](/zh-cn/web-docs/vtc/discord-verification/) 在网站上关联您的 VTC 服务器。
