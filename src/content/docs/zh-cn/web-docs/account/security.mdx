## 访问安全设置

1. 点击右上角的头像
2. 选择 **设置**
3. 选择 **安全** 选项卡
4. 或访问 `trucklinemp.com/user/me/settings?tab=security`

## 关联账户 (Steam)

您的 Steam 账户已永久关联到 TrucklineMP 账户。

- **状态：** 无法解除关联
- **用途：** 主要身份验证
- **Steam ID：** 在此部分显示

此关联是账户验证所必需的，无法更改。

## 双因素身份验证 (2FA)

为您的账户增加一层额外的安全保护。

### 启用 2FA

1. 点击 **启用 2FA**
2. 系统将生成一个二维码
3. 使用您的身份验证应用扫描二维码：
   - Google Authenticator
   - Authy
   - Microsoft Authenticator
   - 任何支持 TOTP 的应用
4. 或手动输入二维码下方显示的密钥
5. 点击 **继续验证**
6. 输入应用中的 6 位验证码
7. 点击 **验证并启用**
8. **保存您的备用代码** - 这些代码将不再次显示

### 备用代码

启用 2FA 后，您将获得 **10 个备用代码**：
- 每个代码只能使用 **一次**
- 如果您无法访问身份验证应用，可使用这些代码登录
- 将它们保存在安全的位置（密码管理器、打印件）
- 您可以一次性复制所有代码

### 禁用 2FA

1. 点击 **禁用 2FA**
2. 输入您的身份验证应用代码 **或** 一个备用代码
3. 点击 **禁用 2FA**
4. 2FA 功能现已从您的账户中移除

**警告：** 禁用 2FA 会降低您的账户安全性。

### 如果您丢失了身份验证设备

1. 使用备用代码登录
2. 登录成功后，前往安全设置
3. 使用备用代码禁用 2FA
4. 使用新的身份验证应用重新启用 2FA

**如果没有备用代码：** 请通过 Discord 联系支持团队，并提供身份证明。

## 开发者模式

启用开发者控制台以访问专业工具。

### 您将获得
- 创建 API 项目
- 管理 API 凭据
- 访问开发者文档
- 构建与 TrucklineMP 的集成

### 启用开发者模式
1. 在开发者模式部分点击 **激活**
2. 阅读确认对话框
3. 点击 **确认激活**
4. 开发者模式现已激活

**警告：** 此操作是永久且不可逆的。

### 访问控制台
- 启用后，点击 **打开控制台** 以访问开发者工具
- 或访问 `trucklinemp.com/developer`

## 活动会话

查看和管理当前登录您账户的所有设备。

### 会话信息
每个会话显示：
- **浏览器** - Chrome、Firefox、Safari、Edge
- **操作系统** - Windows、macOS、Linux、Android、iOS
- **IP 地址** - 会话来源的 IP 地址
- **开始日期** - 会话创建时间
- **当前标识** - 标记您当前会话

### 撤销会话
1. 找到您想要撤销的会话
2. 点击其旁边的 **撤销**
3. 该会话将立即被注销
4. 设备需要重新登录

### 注销所有其他会话
1. 点击顶部的 **注销所有其他会话**
2. 除当前会话外的所有会话都将被撤销
3. 如果您怀疑存在未经授权的访问，此操作非常有用

## 隐私设置

### 隐藏外部配置
- 启用后，您的 Truckline Utils 配置仅对您和管理员可见
- 其他用户无法在您的个人资料中看到您的配置
- 勾选复选框以启用或禁用此功能

## 安全最佳实践

### 基本要求
- **启用 2FA** - 这是最重要的安全步骤
- **保存备用代码** - 将其存储在密码管理器中
- **定期审查会话** - 撤销任何您不熟悉的会话
- **使用强密码** - 密码应专为 TrucklineMP 设置

### 建议做法
- 在共享设备上退出登录
- 定期审查授权应用
- 保持您的关联账户信息最新
- 立即报告可疑活动

## 问题排查

### "我无法启用 2FA"
- 确保您的身份验证应用支持 TOTP
- 检查设备时间是否已同步
- 尝试使用其他身份验证应用

### "我丢失了备用代码"
- 如果仍保持登录状态，请禁用 2FA 并重新启用
- 如果无法登录，请通过 Discord 联系支持团队
- 提供身份证明以进行账户恢复

### "我看到了一个我不熟悉的会话"
- 立即撤销该会话
- 如果可能，请更改您的密码
- 如果尚未启用 2FA，请立即启用
- 如果您怀疑存在未经授权的访问，请联系支持团队

### "我无法通过 2FA 登录"
- 检查身份验证应用的时间是否正确
- 尝试使用备用代码
- 如果问题仍然存在，请联系支持团队
