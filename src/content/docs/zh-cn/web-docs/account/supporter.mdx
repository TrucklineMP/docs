TrucklineMP 提供可选的**支持者**和**高级**订阅。这些订阅有助于为平台提供资金，并可在您的个人资料上解锁装饰性福利——不会带来任何游戏或管理方面的优势。

## 访问账单页面

1. 点击右上角的头像
2. 选择**设置**
3. 选择**账单**选项卡
4. 或访问 `trucklinemp.com/user/me/settings?tab=billing`

---

## 订阅

1. 选择**支持者**或**高级**
2. 点击**订阅**——您将被重定向至安全的 Stripe 结账页面
3. 完成支付
4. 您将被返回账单设置页面，此时您的订阅已生效

您可以随时通过**管理账单**按钮管理或取消订阅，该按钮将打开 Stripe 客户门户。

### 改为关联 Patreon

如果您已在 Patreon 上支持 TrucklineMP，可以直接从[关联设置](/zh-cn/web-docs/account/connections/)关联您的 Patreon 账户，而无需直接订阅——您的等级将被自动识别。此功能需要平台已启用 Patreon 关联。

---

## 订阅权益

| 权益 | 支持者 | 高级 |
|------|:---------:|:-------:|
| 个人资料徽章 | 是 | 是 |
| 个人资料主题 | 是 | 是 |
| 名称样式 | 是 | 是 |
| 头像边框 | 是 | 是 |
| 卡片样式 | 是 | 是 |
| 个人资料装饰 | 是 | 是 |
| 动态名称特效 | - | 是 |
| 动态头像边框 | - | 是 |
| 个人资料氛围效果 | - | 是 |
| 个人资料上的动态媒体 | - | 是 |
| 精选展示 | - | 是 |

高级订阅包含支持者订阅的所有权益。

---

## 问题排查

### “我的结账未完成”

如果支付失败或被取消，则不会创建订阅——请从账单选项卡重新尝试。

### “我的权益未显示”

订阅生效后，权益将自动应用。请刷新您的个人资料页面；如果几分钟后仍未显示，请检查账单设置中的订阅状态是否为**有效**。

### “我关联了 Patreon 但没有获得权益”

请确认您的 Patreon 赞助等级为受支持的等级之一，并且关联状态在[关联设置](/zh-cn/web-docs/account/connections/)中显示为已关联。
