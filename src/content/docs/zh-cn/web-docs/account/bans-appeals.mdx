TrucklineMP 会公布部分管理记录，并在您对封禁或停权决定有异议时提供申诉渠道。

## 公开封禁列表

访问 [trucklinemp.com/bans](https://trucklinemp.com/bans) 查看公开的封禁条目。

每条记录可能包含：

- 违规类别（为保护隐私已作脱敏处理）
- 影响范围（平台、游戏、通信）
- 临时处罚的起始日期
- 封禁状态（进行中或已过期）

单个封禁记录的页面路径为 `/bans/{id}`。

并非所有内部管理备注都会公开。敏感信息仅保留在工作人员工具中。

---

## 您的个人资料与状态

在您的[公开个人资料](/zh-cn/web-docs/account/public-profile/)上：

- 如果您当前处于封禁或停权状态，系统将显示封禁横幅
- 在符合可见性规则的情况下，**记录**选项卡可能会列出您的封禁历史

其他用户仅能看到政策允许公开的内容。

---

## 申诉资格

并非所有封禁都能立即申诉。资格取决于以下因素：

- 封禁类型与严重程度
- 距离上次申诉的冷却时间
- 根据政策该封禁是否为永久性质

当您开始申诉时，支持系统会自动检查您的资格。若不符合条件，表单将说明原因以及您何时可以再次尝试。

---

## 提交申诉

1. 登录收到封禁的账户
2. 打开 [trucklinemp.com/support?lane=appeal](https://trucklinemp.com/support?lane=appeal)
3. 在申诉表单中如实说明情况
4. 在工单线程中等待工作人员审核

申诉**并非**与版主即时聊天。工作人员会阅读您的工单，并在审核完成后予以回复。

### 表单不是法庭

我们不在乎故作专业的腔调。非正式的表达不会扣分，但撒谎则会。

表单会直接询问两件事：

- **这件事是否多少有您的责任？** 请选择“是”、“否”或“视情况而定”。请如实回答，不要猜测工作人员希望听到的答案。
- **事情为何发生？** 请用您自己的话解释。无需写成正式文章，只需直截了当地说明经过即可。

不要假装道歉。如果您确实认为自己没错，请明确说明；如果您知道自己有错，就坦承下来。工作人员能分辨出真诚的解释与程式化的道歉，而诚实的态度无论哪种情况都能加快审核速度。

### 需要包含的内容

- 您认为该决定中有哪些不妥之处（如有）
- 工作人员可能遗漏的背景信息
- 相关证据链接（截图、时间戳等）
- 坦诚直接的语气。敌对态度和明显谎言会延长审核时间，但保持礼貌并非强制要求

---

## 收到裁决后

- **申诉通过**：限制将根据工作人员指示解除。您可能需要退出并重新登录。
- **申诉被拒**：工单将显示裁决结果。您可能需要等待一段冷却时间才能再次申诉。
- **申诉已撤回**：您（或工作人员代表您）在裁决作出前撤回了申诉。

## Discord 封禁

在许多情况下，**TrucklineMP 官方服务器**上的 Discord 管理行为会与平台状态关联。而 **VTC 服务器**上仅涉及 Discord 的问题，则由相应 VTC 的管理员处理，与 TrucklineMP 工作人员无关。

请通过网站支持系统申诉平台封禁，切勿通过 Discord 私信版主。

---

## API 可见性

第三方工具可通过以下接口读取公开封禁数据：

```
GET https://api.trucklinemp.com/bans
GET https://api.trucklinemp.com/bans/{id}
```

OAuth 作用域 `bans:read` 是为未来 userinfo 功能预留的，但**目前不会**在 userinfo 中返回。请参阅 [OAuth 应用](/zh-cn/web-api/oauth-apps/#用户信息响应)。
