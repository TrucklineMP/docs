自定义 TrucklineMP 的外观并管理您的账户偏好设置。

## 访问外观设置

1. 点击右上角的头像
2. 选择 **设置**
3. 选择 **外观** 选项卡
4. 或访问 `trucklinemp.com/user/me/settings?tab=appearance`

---

## 主题

选择 TrucklineMP 的外观。您的主题偏好会自动保存。

### 可用主题

#### 深色
- 默认的马拉松风格
- 深色背景搭配硬朗的工业风设计
- 高对比度文本
- 在低光环境下更护眼

#### 浅色
- 干净的白色背景
- 在明亮环境下提供高对比度
- 专业的外观
- 在光线充足的房间中更易阅读

#### 异常熟悉的灰色
- 深灰色搭配绿色点缀
- 一种感觉莫名熟悉的独特风格
- 中等对比度
- 平衡了深色与浅色主题的特点

### 选择主题
1. 浏览主题卡片
2. 每张卡片都展示了该主题颜色的预览色块
3. 点击主题即可应用
4. 更改会即时生效并自动保存
5. 活动主题上会显示一个小圆点标识

## 引导之旅

如果您想重新体验平台引导流程，可以随时重置并重启引导之旅。

### 重启引导之旅
1. 向下滚动到外观设置选项卡中的 **引导设置** 部分。
2. 点击 **重启引导之旅** 按钮。
3. 这将重置您的引导状态，并立即重启由 John Driver 主持的交互式引导流程。

## 授权应用

管理可访问您账户的第三方应用程序。

### 访问授权应用
1. 前往 **设置** > **授权应用** 选项卡
2. 或访问 `trucklinemp.com/user/me/settings?tab=authorized-apps`

### 什么是授权应用？
您已通过 OAuth 授权访问 TrucklineMP 账户的第三方应用程序。这些应用可能包括：
- 卡车配置工具
- 活动管理工具
- 社区机器人
- 分析仪表盘

### 查看应用
对于每个授权应用，您可以看到：
- **应用名称** - 第三方应用的名称
- **已授予的权限** - 该应用可以访问的内容
- **授权日期** - 您授予访问权限的时间

### 撤销访问
1. 找到您想要撤销访问的应用
2. 点击 **撤销**
3. 该应用的访问权限将立即被移除
4. 如果您想再次使用该应用，需要重新授权

### 何时应撤销授权
- 您已不再使用该应用
- 您怀疑存在未经授权的访问
- 该应用已被泄露或攻击
- 您正在清理旧有的连接

## 数据导出

请求获取 TrucklineMP 存储的您的数据副本。

### 访问数据导出
1. 前往 **设置** > **数据导出** 选项卡
2. 或访问 `trucklinemp.com/user/me/settings?tab=export`

### 包含的内容
您的导出内容包括：
- 个人资料信息（名称、昵称、头像、社交链接）
- VTC 会员历史
- 活动日志
- 配置数据
- 论坛帖子和主题
- 活动参与记录

### 如何请求
1. 点击 **请求导出**
2. 您的导出请求将被加入处理队列
3. 准备就绪后，您将收到一封电子邮件
4. 通过邮件中的链接下载数据文件
5. 下载链接在限定时间内有效

### 数据格式
- 导出数据以 JSON 格式提供
- 所有数据均可由机器读取
- 您可以将其导入其他工具或自行保存记录

## 论坛设置

配置您的论坛偏好设置。

### 访问论坛设置
1. 前往 **设置** > **论坛** 选项卡
2. 或访问 `trucklinemp.com/user/me/settings?tab=forum`

### 可用设置
- **通知偏好** - 控制您接收论坛通知的方式
- **显示选项** - 自定义论坛内容的显示方式
- **签名设置** - 为您的论坛帖子设置签名

## 最佳实践

### 主题
- 选择适合您常用光照环境的主题
- 深色主题更适合夜间驾驶时使用

### 数据导出
- 在删除账户前请求导出数据
- 妥善备份您的数据
- 检查您的数据以了解存储内容

## 问题排查

### “主题没有变化”
- 刷新页面
- 清除浏览器缓存
- 尝试使用其他浏览器

### “我无法撤销应用的授权”
- 确保您的网络连接稳定
- 刷新页面后重试
- 如果问题仍然存在，请联系支持团队

### “我的数据导出尚未送达”
- 检查您的电子邮件垃圾邮件文件夹
- 导出可能需要几分钟处理时间
- 如果超过一小时仍未收到，请联系支持团队
