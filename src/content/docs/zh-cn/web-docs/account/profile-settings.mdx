## 访问个人资料设置

1. 点击右上角的头像
2. 选择 **设置**
3. 选择 **个人资料** 选项卡
4. 或访问 `trucklinemp.com/user/me/settings?tab=profile`

---

## 显示名称

您的公开显示名称对所有用户可见。

- **长度：** 2-32 个字符
- **冷却时间：** 每天只能更改一次
- **可见性：** 在您的个人资料、VTC、活动、论坛和新闻源中显示

### 提示
- 选择一个易于识别的名称
- 避免难以输入的特殊字符
- 保持与其他平台名称一致

---

## 社交媒体昵称

您的个人资料 URL 的唯一昵称。

- **URL：** `trucklinemp.com/@yourhandle`
- **长度：** 2-15 个字符
- **允许字符：** 仅限小写字母、数字和下划线
- **冷却时间：** 每 30 天只能更改一次

### 提示
- 保持简短易记
- 与其他社交媒体昵称保持一致
- 避免看起来像垃圾邮件的数字组合

---

## 头像

您在整个平台显示的头像。

### 上传头像
1. 点击 **上传头像**
2. 选择一张图片文件（JPEG、PNG 或 WebP）
3. 最大文件大小：5 MB
4. 图片将立即上传并应用

### 从 Steam 同步
1. 点击 **从 Steam 同步**
2. 您的头像将从 Steam 帐户刷新
3. 此操作会获取您当前的 Steam 头像

### 提示
- 使用清晰易辨的图片
- 方形图片效果最佳
- 避免背景过于复杂
- 确保在小尺寸下您的面部或徽标清晰可见

---

## 社交媒体链接

添加指向您社交媒体个人资料的链接。这些链接将显示在您的公开个人资料上。

### TikTok
- 输入完整的 TikTok 个人资料 URL
- 示例：`https://www.tiktok.com/@yourname`
- 必须是有效的 TikTok URL

### World of Trucks
- 输入您的 World of Trucks 个人资料 URL
- 示例：`https://worldoftrucks.com/en/profile/...`
- 必须是有效的 World of Trucks URL

### Twitter / X
- 输入您的 Twitter 或 X 个人资料 URL
- 示例：`https://twitter.com/yourhandle` 或 `https://x.com/yourhandle`
- 必须是有效的 Twitter/X URL

### Medal
- 输入您的 Medal 个人资料 URL
- 示例：`https://medal.tv/u/yourname`
- 必须是有效的 Medal URL

### URL 验证
- 所有链接必须以 `https://` 开头
- 链接将根据对应域名进行验证
- 无效的 URL 将显示错误消息
- 如果您输入的 URL 没有 `https://`，系统将自动添加

## 实时预览与保存更改

当您修改个人资料设置时，屏幕右侧会实时渲染一个 **Discord 风格的公开页眉预览卡片**（包括头像、显示名称、昵称、身份标签和个人简介）。这能让您在保存前直观地查看个人资料的外观。

要保存或撤销编辑：
1. 当任何字段被修改时，屏幕底部会弹出一个 **滑动式设置栏**。
2. 点击滑动式设置栏中的 **保存更改** 以应用修改。
3. 点击 **重置** 以放弃所有未保存的编辑并恢复之前的设置。
4. 保存后，更改会立即反映在您的公开个人资料上。

## 问题排查

### “我无法更改名称”
- 名称每天只能更改一次
- 确保您的名称长度为 2-32 个字符
- 检查是否存在无效字符

### “我的昵称无法保存”
- 昵称长度必须在 2-15 个字符之间
- 仅允许使用小写字母、数字和下划线
- 昵称每 30 天只能更改一次

### “我的头像无法上传”
- 检查文件格式（JPEG、PNG 或 WebP）
- 确保文件大小低于 5 MB
- 尝试使用其他图片文件

### “我的社交媒体链接显示错误”
- 确保 URL 以 `https://` 开头
- 检查 URL 是否来自正确的平台
- 删除任何多余的空格或字符
