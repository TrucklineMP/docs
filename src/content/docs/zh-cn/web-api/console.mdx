[trucklinemp.com/developer](https://trucklinemp.com/developer) 上的开发者控制台是管理 API 密钥、OAuth 应用、Webhook 和集成遥测数据的地方。

请先启用访问权限：[开发者平台概览](/zh-cn/web-api/overview/#开始前的准备)。开发者模式一旦激活即永久生效。

---

## 控制台布局

侧边栏分为四个区域：

### 常规

| 页面 | 用途 |
|------|------|
| **仪表盘** | 项目概览卡片、快速链接 |
| **所有项目** | 列表、搜索和创建项目 |

### API 与服务

| 页面 | 用途 |
|------|------|
| **API 密钥** | 为每个项目创建和撤销 `tlmp_api_` 密钥 |
| **OAuth 应用** | 注册和配置 OAuth 应用 |
| **Webhook** | 订阅平台事件推送 |
| **API 库** | 嵌入式的 ReDoc，用于 `/api/v1/openapi.json` |
| **沙箱** | 通过浏览器发送测试请求 |

### 治理

| 页面 | 用途 |
|------|------|
| **分析** | 请求量、错误、延迟、热门端点 |
| **使用配额** | 速率等级显示、突发使用量、可疑标记 |
| **审计日志** | 包含 IP、状态、速率限制命中情况的逐请求日志 |

### 资源

| 页面 | 用途 |
|------|------|
| **API 变更日志** | 已发布的 API 变更历史 |
| **应用目录** | 浏览公开的 OAuth 应用，举报滥用行为 |

---

## 项目

- 每个开发者账户最多可创建 **5 个项目**
- 每个项目拥有自己的 API 密钥和 OAuth 应用
- 从页眉选择活动项目；选择结果会保存在浏览器存储中
- 许多页面支持在 URL 中使用 `?project={id}`

在生成密钥或 OAuth 凭据前，请先创建项目。

---

## API 密钥

- 前缀：`tlmp_api_`（旧密钥可能仍使用旧的 `tl_` 前缀）
- 每个项目最多可拥有 **10 个有效密钥**
- 密钥仅在创建时显示一次
- 提供对公共 REST 数据的只读访问权限以及更高的速率限制
- 若密钥泄露，请立即通过控制台撤销

请参阅 [公共 API](/zh-cn/web-api/public-api/)。

---

## OAuth 应用

- 每个项目最多可创建 **5 个 OAuth 应用**
- 客户端 ID 前缀：`tlmp_client_`
- 未发布的应用需要 **测试用户** 才能进行授权
- 发布应用可能需要人工审核

请参阅 [OAuth 应用](/zh-cn/web-api/oauth-apps/)。

---

## Webhook

- 每个开发者账户最多可创建 **10 个 Webhook**（用户级别，非项目级别）
- 仅支持 HTTPS 端点
- 若签名密钥泄露，请通过控制台进行轮换

请参阅 [Webhook](/zh-cn/web-api/webhooks/)。

---

## 分析与审计

**分析** 会汇总所选项目的流量数据，包括时间线图表、错误率、延迟百分位数以及热门端点或密钥。

**审计日志** 会列出每个请求的方法、路径、状态码、用户代理，以及是否触发了速率限制。可按时间范围和状态进行筛选，用于调试集成问题并排查速率限制的误报。

**配额** 会显示您当前的 API 等级（`free`、`basic`、`premium`、`unlimited`）、有效限制以及任何反滥用状态。等级升级由人工分配；如需商业支持，请联系 [支持团队](/zh-cn/web-docs/account/support-tickets/)。

---

## 沙箱

沙箱会加载最新的 OpenAPI 规范，并允许您将存储在会话中的 API 密钥附加到请求中，以测试 `/api/v1` 下的同源端点。这在编写客户端代码前非常有用。

---

## 应用目录

已发布的 OAuth 应用会出现在目录中供用户发现。用户可以搜索应用并举报可疑条目。请在 OAuth 应用的 **常规** 页面中保持您的隐私政策和网站 URL 准确无误。

---

## API 变更日志

人工发布变更日志条目（包括功能、弃用和破坏性变更）。开发者可在控制台中阅读这些日志。第三方无法自行发布内容。

---

## 控制台不包含的内容

以下 **不是** 第三方集成接口：

| 接口 | 说明 |
|------|------|
| `/api/rpc` | 仅用于网站 UI 的内部 oRPC |
| `/api/v1/mobile/*` | 第一方移动应用 |
| `/api/v1/launcher/*` | 游戏启动器 |
| 管理流程 | 仅限人工审核和等级变更 |

请使用本文档章节中记录的公共 API 和 OAuth 接口。

---

## 限制摘要

| 资源 | 限制 |
|------|------|
| 每个账户的项目数 | 5 |
| 每个项目的 API 密钥数 | 10 |
| 每个项目的 OAuth 应用数 | 5 |
| 每个账户的 Webhook 数 | 10 |
