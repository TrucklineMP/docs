TrucklineMP 为第三方集成提供了开发者平台。您可以通过**公共 API** 读取平台公开数据，使用 **OAuth 2.0** 识别用户，并通过 **webhook** 接收实时通知。

本文档涵盖相关概念和工作流程。如需了解完整的端点列表、请求结构和响应模式，请使用主站上的交互式 API 参考。

## 您可以构建哪些应用

| 集成方式 | 适用场景 |
|-------------|----------|
| **公共 API** | 用于机器人、仪表盘、统计网站以及需要读取 VTC、事件、新闻、用户和管理数据的工具 |
| **OAuth 应用** | 用于让用户使用其 TrucklineMP 帐户登录并读取特定范围的个人资料数据的应用 |
| **webhook** | 用于响应平台事件（如成员加入、封禁、RSVP 等）的服务 |

## 开始前的准备

1. 在 [trucklinemp.com](https://trucklinemp.com) 创建 TrucklineMP 帐户。
2. 在 **帐户设置 → 安全 → 开发者模式 → 激活** 中启用**开发者模式**。
3. 通过导航栏或安全设置打开 [开发者控制台](https://trucklinemp.com/developer)。

开发者模式可解锁控制台，但本身不会授予更高的 API 权限。公共 API 端点仍为只读模式。OAuth 范围用于控制用户在授权后您的应用可以访问哪些用户数据。

## 快速入门：公共 API

1. 在开发者控制台中创建一个**项目**。
2. 生成一个 API 密钥（以 `tlmp_api_` 为前缀）。在显示时将其复制保存，该密钥无法再次查看。
3. 使用您的密钥发送请求：

```bash
curl -H "Authorization: Bearer tlmp_api_YOUR_API_KEY" \
  "https://api.trucklinemp.com/vtcs"
```

4. 在 [API 沙箱](https://trucklinemp.com/developer/playground) 中交互式地尝试各个端点。

公共只读端点**无需** API 密钥即可使用。密钥可提高您的速率限制，并将使用情况关联到您的项目以便进行分析。

## 快速入门：OAuth 应用

1. 在开发者控制台中，前往 **OAuth 应用** 并创建一个应用。
2. 在 OAuth 设置页面配置**重定向 URI** 和**范围**。
3. 从应用概览中复制**安装链接**（或自行构建授权 URL）。
4. 在应用未发布期间，添加**测试用户**，以便其他人在开发期间对其进行授权。
5. 准备就绪后，完成域名验证并通过“发布”页面发布应用。

请参阅 [OAuth 应用](/zh-cn/web-api/oauth-apps/)，了解完整的授权流程、PKCE 和发布规则。

## 隐私与合规性

API 使用情况会被记录，用于速率限制、滥用防范和分析。有关遥测数据如何处理，请参阅[隐私政策](https://id.trucklinemp.com/legal/privacy)。

OAuth 应用在发布前必须提供**隐私政策 URL**，并建议提供**服务条款 URL**。
