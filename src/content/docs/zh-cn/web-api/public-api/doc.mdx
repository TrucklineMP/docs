这是 TrucklineMP 公共 API 的完整规范，通过 Swagger UI 以交互式方式呈现。每个端点、参数和响应模式均根据 [trucklinemp.com/api/v1/openapi.json](https://trucklinemp.com/api/v1/openapi.json) 处的 OpenAPI 规范实时生成。

您可以使用筛选器查找端点，展开某个部分查看参数和示例，然后点击 **Try it out** 发送真实请求。公共只读端点无需 API 密钥即可使用；如需提高速率限制，请从 [开发者控制台](https://trucklinemp.com/developer) 添加 `tlmp_api_...` 密钥。
