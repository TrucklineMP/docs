TrucklineMP features separate directories for Virtual Trucking Companies (VTCs) and Virtual Bus Companies (VBCs) to help drivers and coach operators discover organizations. Browse all public listings, filter by what matters to you, and open a company profile to apply or learn more.

## Accessing the directories

- **VTC Directory**: Open [trucklinemp.com/vtc](https://trucklinemp.com/vtc).
- **VBC Directory**: Open [trucklinemp.com/vbc](https://trucklinemp.com/vbc).

Only **public** companies appear in these directories. Unlisted and private companies are hidden from browsing unless you have a direct link or invite.

---

## Search and filters

Use the toolbar to narrow results:

| Filter | Purpose |
|--------|---------|
| **Search** | Match company name, description, or in-game tag |
| **Status** | Show only validated, verified, official, partnered, or recruiting companies |
| **Language** | Primary language filter |
| **Game** | Show companies for ETS2 or ATS |
| **Tag** | Match the company's in-game tag |
| **Member count** | Minimum or maximum number of members |

### Sort options

- Newest first
- Most members
- Most active
- Name (A-Z)

Results update as you change filters. Pagination loads more companies when available.

---

## Company cards

Each card shows:

- Logo and banner preview
- Company name and handle (`@handle`)
- Slogan or short description excerpt
- Badges (verified, official, partnered, recruitment open)
- Member count
- Primary language

Click a card to open the full company profile.

---

## Company profile overview

From a profile you can:

- Read the full description and rules
- See upcoming events and news
- View member preview and open the full roster
- Apply if recruitment is open
- Join via invite if you have a code
- See a verified Discord server link when configured

Profile URLs use handles: `trucklinemp.com/vtc/@handle` (VTC) or `trucklinemp.com/vbc/@handle` (VBC).

---

## For company owners

To improve discoverability:

1. Set visibility to **public** in [General Settings](/web-docs/vtc/general-settings/)
2. Keep recruitment open if you are hiring
3. Apply for [Verified](/web-docs/vtc-programs/verified/) or [Partnered](/web-docs/vtc-programs/partnered/) status when eligible
4. Post [news](/web-docs/vtc/news/) and [events](/web-docs/vtc/events/) so your profile stays active

Unlisted companies are reachable by direct link but do not appear in directory browse results.

## API access

Third-party tools can list companies through the Public API:

```
GET https://api.trucklinemp.com/vtcs
```

See [Public API](/web-api/public-api/) for authentication and pagination.
