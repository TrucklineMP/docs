La page General Settings est l'endroit où vous configurez l'identité principale et la présence publique de votre VTC.

## Accéder aux paramètres généraux

1. Accédez au panneau de gestion de votre VTC
2. Sélectionnez **General Settings** dans la barre latérale
3. Vous verrez des sections pour Identity, Requirements, Social Links, et Discord Server

---

## Identité de la VTC

### Nom de la VTC
- Le nom d'affichage de votre VTC, visible sur toute la plateforme
- Champ obligatoire
- Les modifications affectent la façon dont votre VTC apparaît dans les annuaires et profils

### Handle de la VTC
- Identifiant unique pour l'URL de votre VTC : `trucklinemp.com/vtc/@yourhandle`
- Maximum 15 caractères
- Seuls les lettres minuscules, chiffres, et tirets bas sont autorisés
- Affiché avec un préfixe `@` dans l'interface
- Modifie l'URL permanente de votre VTC

### Slogan
- Accroche courte affichée sur le profil de votre VTC
- Maximum 60 caractères
- Apparaît sous le nom de votre VTC dans l'en-tête du profil

### Description
- Description enrichie de votre VTC (prend en charge le Markdown)
- Maximum 5 000 caractères
- Champ obligatoire
- Affichée sur le profil public de votre VTC
- Utilisez ce champ pour raconter l'histoire, la mission de votre VTC, et ce qui vous rend unique

### Règles
- Les règles et directives de votre VTC (prend en charge le Markdown)
- Champ obligatoire
- Visible par les membres et les candidats
- Gardez-les claires et complètes

### Logo
- URL de l'image de profil de votre VTC
- Doit être une URL HTTPS valide
- Affiché dans les annuaires, profils, et fils d'actualités
- Recommandé : image carrée, au moins 256x256 px

### Bannière
- URL de la bannière de couverture pour le profil de votre VTC
- Doit être une URL HTTPS valide
- Affichée en haut de la page de profil de votre VTC
- Recommandé : image large, au moins 1920x400 px

## Exigences et recrutement

Configurez qui peut rejoindre votre VTC et comment fonctionne le recrutement.

### Ancienneté minimale du compte
- Définissez l'ancienneté minimale (en jours) qu'un compte TrucklineMP doit avoir pour postuler
- Aide à filtrer les comptes tout juste créés
- Réglez sur 0 pour autoriser tout âge de compte

### Temps de jeu minimum
- Définissez le temps de jeu minimum (en heures) requis pour postuler
- Garantit que les candidats ont de l'expérience avec le jeu
- Réglez sur 0 pour autoriser tout temps de jeu

### Langue principale
- La langue principale de votre VTC
- Choisie parmi une large liste de langues prises en charge
- Affichée sur le profil de votre VTC
- Aide les utilisateurs à trouver des VTC correspondant à leur langue

### Recrutement ouvert
- Bascule pour activer ou désactiver le recrutement
- Lorsqu'activé, votre VTC affiche le statut « Hiring » dans les annuaires
- Lorsque désactivé, votre VTC affiche le statut « Closed »
- N'affecte pas les membres actuels

## Présence sociale

Ajoutez des liens vers la présence en ligne de votre VTC. Toutes les URL doivent être des liens `https://` valides.

### Invitation Discord
- Lien vers le serveur Discord de votre VTC
- Utilisez si possible un lien d'invitation permanent
- Affiché sur le profil de votre VTC

### URL du site web
- Le site web officiel de votre VTC
- Affichée sur le profil de votre VTC
- Doit être une URL HTTPS valide

### Email public
- Adresse email de contact de votre VTC
- Affichée publiquement sur votre profil
- Doit être une adresse email valide

### Instagram
- Lien vers le profil Instagram de votre VTC
- Doit être une URL HTTPS valide

### Twitter/X
- Lien vers le profil Twitter ou X de votre VTC
- Doit être une URL HTTPS valide

### Facebook
- Lien vers la page Facebook de votre VTC
- Doit être une URL HTTPS valide

## Enregistrer les modifications

- Cliquez sur **Save Configuration** en bas à droite pour appliquer les modifications
- Un bouton d'enregistrement flottant apparaît lorsque vous faites défiler
- Les modifications prennent effet immédiatement
- Une notification de succès s'affiche une fois enregistré

## Bonnes pratiques

### Complétion du profil
- Remplissez tous les champs pour une apparence professionnelle
- Utilisez des images de haute qualité pour le logo et la bannière
- Rédigez une description convaincante qui raconte votre histoire
- Gardez les règles claires et complètes

### URL
- Utilisez des liens permanents lorsque possible
- Testez tous les liens après l'enregistrement
- N'utilisez que des URL HTTPS

### Paramètres de recrutement
- Fixez des exigences raisonnables pour filtrer les candidats
- Gardez le recrutement ouvert quand vous recherchez activement des membres
- Mettez à jour la langue pour correspondre à votre communauté

---

## Dépannage

### « Je ne peux pas enregistrer mes modifications »
- Assurez-vous que tous les champs obligatoires sont remplis (nom, description, règles)
- Vérifiez que toutes les URL sont des liens HTTPS valides
- Vérifiez que le format de l'email est correct

### « Mes images ne s'affichent pas »
- Assurez-vous que les URL sont accessibles publiquement
- Utilisez des liens directs vers les images (pas des liens de page)
- Vérifiez que les URL commencent par `https://`

### « Je veux changer le handle de ma VTC »
- Les handles peuvent être modifiés dans General Settings
- Cela modifie l'URL de votre VTC
- Les anciennes URL ne redirigeront pas
